## 关键业务证据

后端测试覆盖：

- 单选正确/错误，多选全对/漏选/误选，判断 true/false，填空标准/等价匹配、首尾空白和大小写敏感、未命中待复核。
- 自动校验后不可直接发布；批准与发布是独立动作且有顺序审计；来源不匹配不能批准。
- 跨科版本、文档、题目导入、作答拒绝；混合非法归属批次不产生半批题目；练习按外科版本过滤明确拒绝。
- 同逻辑请求重复与并发提交只产生一次 Attempt；改动同键内容被拒绝；真实提交失败注入后 Attempt/卡片/计划完成均回滚。
- 填空复核以独立结论追加，原始结果保留，重复确认仅推进一次；增加等价答案新建待审版本，不绕过发布。
- 固定的10分钟、24小时、72小时、7天、14天间隔及错误重置；暂停手动作答不解除暂停或改写到期。
- 预算容纳不下多选时跳过并继续选择较短题；延期跨日保留；同日重新规划可保留已完成历史，并针对新到期事件安排后续任务。
- 后续答对不抹除历史错误，归档不允许新练习；新版发布不重算旧作答，也不将旧版作答冒充新版练习覆盖。
- Demo 初始化重复运行不复制课程/题目，不批准或发布；备份恢复保留来源/版本/历史；CLI 与网页共享数据库。
- 导入提交发生临时失败时留失败任务；恢复后使用相同规范化输入与幂等键可重试，不因字段默认值不同误报冲突。

浏览器测试覆盖：

1. 人工批量批准→独立发布→填空未命中→人工确认错误→历史错题可见。
2. 创建课程→创建章节→真实 PDF 上传→390px移动导航。
3. 单选作答并显示正确结果、完成一轮。
4. 多选完整集合提交并显示正确结果。
5. 判断布尔值提交并显示正确结果。
6. 填空命中已审核答案并显示正确结果。
7. 首页、课程、题库、练习、错题、计划、审核、设置在1440px与390px下可渲染，无页面运行时异常和横向溢出。
8. 拦截所有非本机域名后，重新规划→延期至下一学习日→刷新仍保留；没有发起外部域名请求。

最后一项验证的是“阻断外部请求仍可工作”，未对用户机器执行断网或改动系统网络配置。未在真实 Edge/Firefox/Safari、手机硬件或其他 OS 单独复测。

## 已知限制与观察

- 正式 SRS 与验收矩阵仍待按实际产品决策修订；本轮没有冻结基线或把未决规则标成批准。局部策略见 [DEMO_POLICIES.md](DEMO_POLICIES.md)。
- 没有对10,000题/100,000 Attempt 的候选性能夹具进行p95压力验证；当前读接口未做完整服务端分页，不能将小样例速度视为大库性能保证。
- 题目富文本修订页面、知识点可视化编辑、OCR、主观评分、复杂后台任务/取消/断点续传均未交付；前两项可作为后续增强。已有共享服务/API支持新版本修订，CLI支持知识和题目受控导入。
- PDF 上传为同步解析，页面显示处理中与终态，尚非独立后台任务队列。模型答案语义正确性仍需人工对照教材确认，原文匹配不是事实正确性证明。
- Playwright输出出现过 Node 的 NO_COLOR/FORCE_COLOR 环境提示。最终通过的一次快速切页过程中，Windows asyncio Proactor还出现一次 WinError10054 连接重置日志；该轮8项测试均通过，未发现数据丢失。保留为连接日志噪声待优化，不能宣称运行日志完全无告警。
- 已实际运行 Windows 11 / PowerShell 7.6.5。Windows PowerShell 5.1、完全未安装Python/Node的机器及跨应用版本恢复未单独验证；这些不列为已通过。
