# ExamPilot D-13 错题集合审查建议（候选，未批准）

- 日期：2026-10-21；阶段：01 需求分析。
- **状态**：仅提出 D-13 候选；D-03、D-05、D-12 已批准，D-13 未批准。
- 关联：FR-07/08，RV-12，AC-07-N/X/I、BC-08；跨项 D-10/14/22/23。

## 1. 需要区分三个概念

1. **历史错题**：某题曾产生正式且已确认的错误判分 Attempt。之后做对仍保留过去的错误记录，提供复盘证据。
2. **当前待巩固**：当前按获批学习状态规则需要继续练习或复习的题目。不是“历史错题”的同义词；其精确成员及到期边界需与 D-14 确认。
3. **待复核作答**：尤其是 D-12 已批准的填空题未匹配答案；其结果尚未判定，不能直接进入历史错题或被视为新错误。待复核存储、确定结论后的唯一更新在 D-22 细化。

## 2. 推荐方案 A（建议批准）

- 错题页**默认显示“待巩固”**，旁边独立标签可切换到“历史错题”，另有“待复核作答”的显式入口或提示。
- “历史错题”按逻辑题聚合并能展开具体作答记录/所见版本，任一次已确认的错误不因后续答对而删除；明确新旧版本与来源。
- “待巩固”由当前的学习/复习调度状态决定，不简单以“上一次是否答错”替代；精确 new/learning/relearning/review 到期边界由 D-14、D-15 决定。
- 支持按**科目、章节、知识点**筛选；只能看到有权限的当前科目资料，归档或失效版本的历史可查，但不得加入新的普通练习或每日计划。
- D-12 下填空题“待复核”不得计为错误 Attempt 或改变复习状态；待最终判定后按 D-22 的单次生效规则更新。
- 弱项统计分母、近期窗口、小样本显示仍留 D-23；D-13 不擅自规定掌握度计算。

## 3. 其他备选

- **方案 B：历史错题优先**。保持与 A 相同的数据保全与筛选规则，但错题页默认展示曾做错的题。优点是熟悉传统错题本；缺点是会把早已巩固的旧错题和当前急需复习的题混在首页。
- **方案 C：合并单列表**。以标签方式标注历史错误/当前待复习/待复核。此方案需要严格保持三种不同来源，不建议在 MVP 合并，因为容易误将待复核记成错题。

## 4. 需要用户裁决的点

- 默认呈现：待巩固（A）还是历史错题（B）？
- 两类集合是否分开展示（推荐），以及旧题归档后仅历史可见而不可再刷（推荐）。
- 待复核答案独立于错题集合，不参与错题统计直到结果确定（与 D-12 一致；事件细节留 D-22）。
