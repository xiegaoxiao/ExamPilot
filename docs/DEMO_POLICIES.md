# ExamPilot 可运行 Demo：执行授权与局部策略

日期：2026-10-21。依据本轮用户直接提供的《可运行 Demo 开发任务》，已授权实现、安装依赖、初始化 Demo 数据、构建和测试。这是对早期“仅需求评审”执行范围的明确更新，**不批准正式 SRS 基线、不改写历史决策、不自动关闭 RV**。原 SRS v0.1、决策台账及评审报告保留。

## 本轮必须遵守的规则

- 四题型：单选四选一；多选四选二至三、集合全匹配；判断布尔；单空短文本等价答案匹配。
- AI 题自动校验后仍需用户批准，再独立发布；来源无效/标记歧义不能绕过校验；所有动作留审计。
- 待复核填空不立即判错、不调度；原 Attempt 追加不可覆盖，复核以单独 Resolution 追加，一次结算。
- 题目版本保留；新版本发布前旧有效版继续可练，旧作答按旧答案解释。
- D-14：首次错→relearning +10分钟；首次对/relearning对→learning +24小时；learning再对→review +72小时；review连续对→7天、14天，14天封顶；非暂停状态错→relearning +10分钟。
- 暂停期间手动作答保留历史，冻结卡片，恢复原状态/到期，过期则立即成为到期。
- D-15：每科预算，到期→弱项新题→其他新题；估时2/3/1/2分钟；装不下跳过并继续，不超自动排题预算；刷新不改已生成计划，主动重新规划保留完成和手调记录。
- 本轮 D-16 执行要求：可见可配时区默认 Asia/Shanghai；自然日计划；0～7日冲刺，仅同层重点章节优先，不改 due_at 或自动扩预算。该实现不将历史 D-16 的“待批准”记录改写为正式批准。

## 未决项的可替换 Demo 局部策略

| 议题 | 临时实现 | 业务保证 |
|---|---|---|
| D-08 删除/归档 | 网页仅提供非破坏性归档，未暴露物理删除；空对象删除留后续 | 原资料、题目、历史保留，不引入强制级联清理 |
| D-09 科目/章节 | 所有课程对象按显式科目及目标章节校验；全局首页和全工作区备份是明确的全局操作 | 同名/同哈希不授予跨科混用；外部文件权限仍需平台配合 |
| D-10 修订 | 所有实质更改新建待审版本；发布新版归档旧版；语义变化使卡片重新学习+10分钟并留迁移审计；暂停保留暂停 | 等价答案扩充也新建版本，但标记非语义变更，不清空既有进度；不修改旧 Attempt |
| D-11 导入 | 一批事务；结构/归属失败整批不入库；精确内容指纹重复跳过映射，近似题干≥0.94相似度提示送审 | 同键异内容拒绝；待审是新增子集，不重复加总；失败任务在回滚后单独留痕 |
| D-12 标准化 | 填空只去首尾空白，大小写/标点不自动替换；等价答案经审核后才影响未来匹配 | 不把未匹配答案直接判错 |
| D-13 待巩固集合 | 当前有效已发布卡片、非暂停且 due_at≤当前时刻；未来、新题、历史错题分开 | 第一次错后10分钟尚未到期时去“未来复习”查看，不伪造到期 |
| D-16 同层顺序 | 到期题按最早due_at；相同due_at再按冲刺重点、章次序、创建时间和ID；新题同层按重点、章次序、创建时间和ID | 考试窗口严格0≤本地日历日差≤7；时区变化不制造 Attempt |
| D-17/18 知识与来源 | 知识点唯一归属科目/章节；先受控导入，再引用；同哈希可按科目/章节独立登记 | PDF物理页从1起，片段去空白后须出现在该页；发布重验文件哈希；无证据只待审 |
| D-19 冷备份 | 建议停止服务，同时取得业务写锁；同应用0.1.0/结构1恢复 | 先清单/摘要/引用验证，拒绝覆盖非空工作区；不保证跨版恢复 |
| D-21 环境与上限 | 名称80字符；PDF50MiB/500页；预算0～240；练习1～100；填空200字符 | 明确报错，不把这些值写成正式批准的产品决策 |
| D-22 复核事务 | 待复核 Attempt.initial_result 永久保留；单独唯一 Resolution；正式结论生效时才推进卡片与今日计划 | 重复确认相同结论返回原结果，不同结论拒绝；过期版本仅确认历史，不迁移掌握度 |
| D-23 薄弱项与统计 | 近30×24小时、按知识点至少3次已判作答、正确率<70%；不足样本不判弱；待复核排除。覆盖率只统计当前有效发布版本有正式判分的题，正确率为全部已判历史事件 | 设置页显式标记临时；实际作答总量与已判正确率分母区分；历史错误事件永久保留，旧版练习不冒充新版覆盖 |
| D-24 CLI/审计 | 默认codex主体；仅显式--human-confirmed声明既有用户批准可用user主体执行批准/发布 | 不是认证或OS沙盒，Agent不得伪造授权；本地单用户API视为用户交互，未知网页来源写入拒绝 |

计划项延期至明确日历日时保留 Deferral，影响入计划资格，不改卡片原 due_at。手动移除仅限当前日，次日重新评估；恢复受当日预算限制。明确重新规划保留已完成项，若同题在当日再次真实到期，可追加新任务；已花费的预算仍计入今日总量。调低预算不能撤销已经发生的完成记录，不再自动追加超预算项。

## 保证边界

本地网页默认127.0.0.1，生产前端无 CDN。AI 生成只在外部 Codex 上由用户发起，项目服务不自动上传。单用户无登录：请求来源和路径校验不能防止本机拥有文件权限的进程直接改文件；Agent必须遵守AGENTS。

自动检查覆盖结构、答案域、引用、精确/近似去重提示、页码、原文片段和原件哈希；语义事实与单选唯一性的最终可靠核验仍需人工对照教材。不得把“检查无已知问题”显示为“模型事实正确性已获证明”。

本文件只解释 Demo 行为，不替代正式需求确认。扩大题型、调度规则或批准权限必须依据用户后续明确授权。
