# ExamPilot 视觉系统

Vue 3 SPA，Tailwind v4；Naive UI 负责消息、确认弹窗和模态框，业务表单使用有标签的原生控件。用户指定蓝色、专业、明亮浅色、留白充分；本 Demo 不增加深色模式。

颜色由 refactoring-ui 的调色脚本生成，源文件为 design-tokens.json；theme.css 是 Tailwind v4 输出，tokens.css 供独立 CSS 使用，preview.html 用于检查色阶。所有业务组件使用语义颜色。正文 ink、辅助 muted、提示 subtle，辅助与提示受对比度下限约束；正常字重400，强调600。

字号12/14/16/18/20/24/30/36/48；间距4/8/12/16/24/32/48/64；卡片圆角16，控件8。空间优先用于划分任务层次，组间距离大于组内距离。每页一个主要动作，其余动作降为描边或文字按钮；确认发布、归档等用模态框讲清实际影响。

桌面固定侧栏与顶部课程上下文；小屏侧栏折叠，内容单列。卡片以细边界分组，阴影仅用于悬浮层。状态始终使用文字与图标辅助，不单靠颜色；原生控件有可见标签、焦点环与禁用反馈。

指标与图形必须读取 API，空数据使用说明与真实入口，不生成展示用百分比或随机趋势。若新增视觉值，先更新 token 源及对比度矩阵，再使用；不得逐页随意添加颜色、字级或圆角。
